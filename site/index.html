    How this page stays true

    Two directions, and only one of them can be true:

    python3 tools/scan.py reads this machine and writes site/state.json. It refuses to write if the document would contain an address, a volume path, a key or a token, and it fails when a folder or a repository has no description.

    python3 tools/scan.py --check validates the committed file without a workspace. CI can only run this one: it proves the shape and the absence of sensitive text, not that the contents are current.
